Rules that hold the set together

  1. One ink weight. 11 units on a 256 grid for every contour, 8.5 for interior detail. Round caps and joins. The line never tapers.
  2. A measured hand, not a shaky one. Anchors are nudged off true and edges bowed before any noise filter runs — but the amplitude is held low on purpose. Push the wobble further and the set reads as a child's drawing instead of a considered one.
  3. The paper shape misregisters. One flat accent per icon, unoutlined, offset down and left like a colour plate that slipped on press. Behind the line, never filling it.
  4. Every icon must work without its accent. If the ink-only cut above is ambiguous, the drawing is wrong — colour is not allowed to carry meaning.
  5. No shadows, no gradients, no second outline. That is what keeps this set distinct from the playful clay set — never mix the two.
  6. Built for 32. Nothing thinner than 8.5, no gap under 20 units, and detail earns its place only if it survives the strip above. A subject that needs fine internal structure gets swapped, not thinned — which is why the driver became a flag.
  7. Warm grounds. These are drawn for ivory and swatch tiles, not for white.
