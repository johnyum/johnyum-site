How this tier differs from the icons

  1. Thinner relative line. 7.5 units against the icon set's 11, on the same 256 grid. Illustrations are read large; an icon's weight looks clumsy there.
  2. Composed, not contained. An icon fills its box evenly. An illustration can sit off-centre, run out of frame, and leave the ground doing real work.
  3. Humanistic motifs first. Hands above all — they carry the human–AI collaboration idea that the whole identity rests on. Then profiles, bulbs, books, botanicals, knots, node constellations.
  4. The ground is part of the drawing. These are built for full swatch fields, not for white cards.
  5. Same non-negotiables. One accent, misregistered, behind the line. No shadows, no gradients, no second outline. Must read with the accent removed.
